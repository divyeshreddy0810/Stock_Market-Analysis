
Code_explanation.txt

1. pipeline/etl.py

    Clean stock data and add features (MA20, MA50, HL Spread)

2. services/data_loader.py

    Fetch stock data from Yahoo Finance

    Apply ETL cleaning & feature engineering

3. utils/preprocessing.py

    Scale prices

    Convert to LSTM sequences

4. models
    lstm_model.py

        Train LSTM on historical data

        Predict past + forecast future

        Compute RMSE & MAPE

    rl_agent.py

        Simple RL agent (threshold-based)

        Recommends Buy/Hold/Sell based on forecast vs current price

5. visuals/plots.py

    Plot historical prices, LSTM predictions, and forecasts

6.app.py

    Streamlit UI

    Inputs: ticker, exchange, price type, forecast days

    Shows charts, metrics, and RL recommendation

7.requirements.txt

    Python dependencies
